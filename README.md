# Хана Финкельштейн — лендинг (HE / RU)

Статический сайт. Сборки нет — Vercel раздаёт файлы как есть.

- `index.html` — сайт (production)
- `assets/` — логотип, портрет, фото
- `design/` — исходник дизайна (для правок)
- `vercel.json` — cleanUrls + кэш картинок

## Цикл выпуска
1. Правка → новая версия файла
2. Commit + push в `main`
3. Vercel сам выкладывает сайт (preview на ветках, production на `main`)

## После первого деплоя
Один раз заполнить форму на живом сайте и подтвердить письмо FormSubmit в FINKEL.HANA@GMAIL.COM.
